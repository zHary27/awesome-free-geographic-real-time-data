# awesome-free-geographic-real-time-data

A list of sources for real-time data that fits a few important criteria for accessibility.

Feel free to contribute with any criteria that should be updated/added, websites that should be here, or ones that shouldn't according to criteria.

### Criteria

Each source should meet these criteria:

* **Free**: accessible without a paid subscription
* **Real-Time**: live or near-real-time data
* **Geographic**: data is tied to real-world locations
* **Worldwide**: global coverage, not limited to one country or region
* **Publicly Accessible**: anyone can open and explore it

## Weather

* [Lightning Map](https://www.lightningmaps.org/); Live lightning strikes worldwide.
* [Weather Data](https://openweathermap.org/api); Global weather data and forecasts.
* [Global Weather Map](https://earth.nullschool.net/); Animated wind and weather conditions.
* [Satellite Weather Map](https://worldview.earthdata.nasa.gov/); Near-real-time satellite imagery.

## Air Quality

* [Air Quality Map](https://explore.openaq.org/); Global air quality measurements.
* [Air Quality Map](https://map.purpleair.com/air-quality); Live particulate pollution sensors.

## Radiation

* [Radiation Map](https://simplemap.safecast.org/); Global radiation sensor readings.
* [Radiation Map](https://www.gmcmap.com/); Live Geiger counter readings.

## Earthquakes

* [Earthquake Map](https://www.seismicportal.eu/realtime.html); Recent earthquakes worldwide.
* [Seismic Sensor Map](https://raspberryshake.org/legacy-data); Live seismic sensor activity.
* [Earthquake Map](https://earthquake.usgs.gov/earthquakes/map/); Global earthquake locations and magnitudes.

## Aircraft

* [Flight Map](https://map.opensky-network.org/); Live aircraft positions worldwide.

## Satellites

* [Satellite Tracking Map](https://network.satnogs.org/); Satellite observations and ground stations.

## Oceans

* [Ocean Sensor Map](https://www.ocean-ops.org/board); Global ocean observing platforms.

## Fires

* [Wildfire Map](https://firms.modaps.eosdis.nasa.gov/map/); Active fires detected by satellites.

## Natural Disasters

* [Disaster Map](https://www.gdacs.org/); Global disaster alerts and events.

## Fishing

* [Fishing Activity Map](https://globalfishingwatch.org/map/); Global fishing vessel activity.

## Floods

* [Flood Map](https://global-flood.emergency.copernicus.eu/map); Global flood monitoring and forecasts.
